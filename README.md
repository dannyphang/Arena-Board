# Arena-Board

This is a full-stack web application built with React, Vite, Express, and Socket.IO. 

## Tech Stack

- **Frontend:** React, Vite, Tailwind CSS
- **Backend:** Node.js, Express, Socket.IO
- **AI Integration:** Google GenAI
- **Language:** TypeScript

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or bun

### Installation

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install --legacy-peer-deps
   # or
   bun install
   ```

### Running the Project

To start the development server, which serves both the API and the Vite frontend:

```bash
npm run dev
# or
bun run dev
```

The application will be available at `http://localhost:3000`.

### Available Scripts

- `npm run dev`: Starts the development server using `tsx`.
- `npm run dev:frontend`: Runs only the Vite frontend development server.
- `npm run dev:server`: Runs only the backend server.
- `npm run build`: Builds both the frontend and the backend.
- `npm run start`: Starts the production server.
